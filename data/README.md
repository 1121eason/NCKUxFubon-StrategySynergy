# 彙總資料與計算範圍

[reviewed-metrics.json](reviewed-metrics.json) 收錄四個 2022–2023 年比較指標。`base` 為 2022，`current` 為 2023。每項保留來源、單位、範圍與核對狀態。

| 指標 | 2022 | 2023 | 單位與範圍 |
|---|---:|---:|---|
| 流通卡 | 479.24 | 721.45 | 小組報告 p.12 原表數值；原表未印單位 |
| 有效卡 | 327.69 | 549.18 | 小組報告 p.12 原表數值；與流通卡同尺度 |
| 營業費用 | 30,029,906 | 37,992,294 | 新台幣仟元；銀行與子公司合併 |
| 本期淨利 | 24,963,587 | 24,448,162 | 新台幣仟元；銀行與子公司合併 |

卡量原表的量級與「萬張」一致；官方 2023 年報所述有效卡約 549 萬亦可交叉檢查量級。公開工具直接使用原表尺度計算比率，不將推定尺度轉成官方核驗的精確卡數。未重新取得逐月監理明細。

財務數值已與 [官方 2023 年報](https://www.fubon.com/banking/document/about/intro_FBB/TW/TaipeiFubonBank112.pdf) 印刷 pp.196、209 核對；2022 為該表重編比較數。銀行合併科目不等於信用卡損益。卡片指標屬業務指標，不可和銀行合併財務數字加總。

## 算式

- 成長率：`(2023 數值 / 2022 數值 - 1) × 100`。
- 有效卡占比：`有效卡 / 流通卡 × 100`。
- 占比變動：兩年百分比相減，以百分點（pp）表示。

工具輸出 [calculated-metrics.json](calculated-metrics.json) 與 [成長圖](../assets/growth-review.svg)。可在 repo 根目錄執行：

```bash
python3 scripts/review_metrics.py
python3 scripts/review_metrics.py --write
```

第一個指令計算並檢查輸出檔是否一致，第二個更新衍生檔。算式核對不會驗證原始數據真實性、個案因果關係、信用卡獲利或實際綜效。
